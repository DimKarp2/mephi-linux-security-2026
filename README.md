# ДЗ №1 Изучение средств защиты ОС GNU/Linux

Работа выполнена в РЕД ОС 8.

## Краткое описание выполнения

### Раздел 1. Создание пользователя

Создан пользователь `user1` с UID `1234` и основной группой `students`.

Для пользователя установлен максимальный срок действия пароля — 90 дней.

Основные команды:

```bash
groupadd students
useradd -m -u 1234 -g students user1
passwd user1
chage -M 90 user1
```

### Раздел 2. Мониторинг файлов и процессов

Выполнен поиск всех файлов с установленным битом set-UID:

```bash
find / -type f -perm -4000 2>/dev/null
```

Также выполнен поиск процессов, у которых эффективный UID равен `0`, а реальный UID принадлежит обычному пользователю:

```bash
ps -eo pid,ruid,euid,user,comm,args | awk '$2 != 0 && $3 == 0'
```

Для проверки был запущен `passwd` от пользователя `user1`. В результате был найден процесс с `RUID = 1234` и `EUID = 0`.

### Раздел 3. Механизм set-UID

В качестве утилиты выбран `cat`.

Копия `/usr/bin/cat` помещена в `/home/user1/cat`, владельцем назначен `root` и установлен бит set-UID:

```bash
chown root:root /home/user1/cat
chmod 4755 /home/user1/cat
```

Обычный `cat` от имени `user1` не смог прочитать `/etc/shadow`, а копия с set-UID выполнила чтение успешно.

### Раздел 4. Linux capabilities

В качестве утилиты выбран `chown`.

Копии `/home/user1/chown` была назначена capability:

```bash
setcap cap_chown+ep /home/user1/chown
```

Обычный `chown` от имени `user1` не смог изменить владельца файла `root`, а копия с `CAP_CHOWN` выполнила операцию успешно.

### Раздел 5. Механизм sudo

Пользователю `user1` разрешено выполнять `/usr/bin/date` от имени `root`.

В `/etc/sudoers` добавлено правило:

```text
user1 ALL=(root) /usr/bin/date
```

Изменение системного времени через `sudo` проверено успешно.

### Раздел 6. Сбор артефактов

Создан скриншот с уникальным номером и сохранены история команд, параметры файлов, capabilities и результаты мониторинга.
